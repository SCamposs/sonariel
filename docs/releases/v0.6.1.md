# Sonariel v0.6.1

## Complete Medium FP32 source-audio recipe

- Use Medium DiT FP32 with **SAME-L encoder and decoder FP32**, T5Gemma FP16, eight steps, CFG/APG 1, six CPU threads and batch 1.
- Choose **With source audio** in the recommended music recipe. The distinct `medium-fp32-same-l-audio-v1` recipe starts at transformation `init_noise_level=0.65`; select a registered source, original direction and seed through Codex. Full-source duration is 5–120 seconds. Lower transformation retains more source content; the value is not a similarity percentage.
- The source encoder is an explicit optional 1.72 GB download; the complete additional FP32 set totals 9.31 GB. Existing verified files are reused. Re-link an existing installation to verify the additional encoder and resampler.
- Text fidelity and compact remain available. Existing text presets keep their identities and values. The compact SAME-S encoder is never silently substituted for SAME-L.
- Preserve the source, hashes, codec/precision metadata and preset/job lineage. Saving a preset does not generate or install anything; existing confirmation, request-key and memory safeguards remain.

The CPU profile still requires 12 GiB available RAM for admission. Durations, workloads and machines affect resource use. See the [validation report](v0.6.1-validation.md) and [complete recipe guide](../MUSIC_RECOMMENDATIONS.md#complete-source-audio-recipe-v061). This remains an experimental local engine, not a universal quality guarantee. Windows installer/updater lifecycle caveats remain documented.
