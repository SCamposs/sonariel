# Sonariel v0.4.0

[Português (Brasil)](https://github.com/SCamposs/sonariel/blob/v0.4.0/docs/releases/v0.4.0.pt-BR.md)

## Production workflow

- English and Brazilian Portuguese interface, language selection, localized diagnostics and workflow tutorial.
- Batch WAV export with verified copies, collision handling and optional portable metadata.
- Versioned music presets with explicit parameter review before generation.
- Non-destructive reference/source excerpts with engine/role validation, hashes and lineage.
- Project tags, combined persistent library filters and incremental card rendering.
- Independent workspace scrolling and FX draft retention while switching modules.
- Atomic schema-5 migrations, consistent backups and recovery regressions.
- Development builds refuse to overwrite a running core runtime.

Voice Studio, experimental Stable Audio, native FX, MCP and optional Audacity remain available with their existing engine limits. Models are downloaded/prepared separately; no GPU, SFT or active-inference cancellation is introduced. CPU RAM gates are unchanged.

## Loops

Loop creation is disabled in packaged UI, MCP and core pending human musical acceptance. Existing WAVs, metadata, recipes and lineage remain preserved and exportable. Previously queued loop requests are interrupted before processing. Reference excerpts and ordinary FX remain available. Issue #3 stays open; two earlier listening rounds were rejected.

## Validation and accepted caveat

Windows installation/basic use was validated with the release candidate in a disposable Windows 11 VM: core startup, EN/PT-BR, tutorial, project creation, WAV import, playback transport, verified export and reopening. Automated regressions, packaged MCP, isolated native FX and SQLite schema 3 → 5 migration passed. The stable build changes version identity and release documentation from that candidate and is rebuilt/signed separately.

**The complete official v0.3.2 → v0.4.0 installer/updater lifecycle was not tested.** The maintainer explicitly accepted this documented caveat and authorized stable publication. Database migration tests do not prove installer restart or preservation of every WebView preference. No automatic downgrade is provided; older cores refuse newer databases. Preserve backups before updating.

The VM's audible output and uninstaller were not validated. Its FX preview correctly waited for 3 GiB free and was cancelled before execution; packaged native FX passed separately outside the VM. See the [full Phase 2.7 report](https://github.com/SCamposs/sonariel/blob/main/docs/PHASE2_7.md).

Updates require an explicit installation action. Tauri update signing is separate from Windows Authenticode; an unknown-publisher warning may remain. Temporary A/B selection and unsaved FX drafts are not persistent project data. Stable Audio/voice remain experimental under their documented licenses and hardware requirements.
