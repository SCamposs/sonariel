# Sonariel v0.2.0

- Tutorial opcional de primeiro uso, reaberto em **Instruções do workflow**, com seis etapas e progresso animado.
- Correção da barra horizontal que piscava durante a troca de etapas; scroll vertical continua disponível em janelas curtas.
- **Versão & atualizações** no número da versão da sidebar. Verificação ao abrir e a cada hora, opcional; instalação somente após confirmação.
- Indicador âmbar quando há atualização. Pacotes com assinatura criptográfica e versão vinculada; instalador Windows reabre o app após atualizar.
- Proteções para não atualizar durante geração, fila pendente, setup ou conexões MCP abertas.
- Licença própria source-available: uso comercial das músicas permitido; venda do aplicativo, de versões modificadas ou de acesso como serviço pago proibida sem autorização separada.

## Instalação

Baixe **Sonariel_0.2.0_x64-setup.exe**. A versão 0.1 precisa receber este instalador uma vez manualmente para ganhar o atualizador. Depois, use o botão de versão na sidebar.

Windows x64, CPU / Turbo / DiT-only. Os modelos são baixados separadamente após autorização. A fila exige 16 GiB livres para carregar o modelo, com uma geração por vez.

O instalador não possui assinatura de editor Windows/Authenticode. A assinatura do atualizador protege o pacote, mas não remove avisos de editor desconhecido. O programa e suas dependências possuem licenças distintas; referências e áudios não acompanham esta release.
