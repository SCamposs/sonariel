# Sonariel v0.6.0

## Clearer production workflows

- Choose music, voice or an existing WAV first; see requirements and a next step before technical forms.
- Continue creative direction through Codex. Manual setup/profile creation is an explicit choice, with contextual help and clearer actions, status and input spacing.
- FX asks for a source before showing processing/export controls. Voice and FX drafts survive navigation in memory and reset when changing projects.
- Codex connection registration now provides visible progress, success and recovery feedback. Configuration still requires the client to reload its MCP connection.

## Recommended music recipe

Medium DiT FP32 + SAME-L FP32 decoding is highlighted as a quality starting recipe, based on the maintainer's local listening evaluation. It preserves T5Gemma FP16, eight steps, CFG/APG 1, six CPU threads and batch 1. This is not a universal quality guarantee.

The profile remains optional: 7.60 GB of additional verified models, separate terms/download authorization and 12 GiB available RAM for admission. Compact stays the lighter default; Turbo remains the baseline. Fidelity supports text-to-audio only, 5–60 seconds; source-audio experiments are not announced as native support.

MCP adds public recipe discovery and explicit project-preset creation. Saving requires a prompt, seed and duration and never starts inference. Exact recipe origin/checkpoint hashes are retained through revisions and production lineage. No private music, prompts or references are distributed.
